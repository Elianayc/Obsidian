## Cascading Style Sheets

### Función principal
Define la **presentación visual y el diseño** de una página web.

Mientras HTML establece la estructura, CSS determina cómo se visualizan los elementos de la interfaz.

**Permite controlar**:
- Colores.
- Tipografías.
- Tamaños.
- Espaciados.
- Distribución de elementos.
- Diseños responsivos.
- Animaciones.

CSS transforma una estructura HTML básica en una interfaz visual atractiva y adaptable.
