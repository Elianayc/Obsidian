Método para solucionar un problema.

Secuencia finita de instrucciones, reglas o pasos que describen en forma precisa las operaciones que una computadora debe realizar para llevar a cabo una tarea en tiempo finito.

#### Características
- Debe ser preciso. Indicando el orden de realización de cada paso.
- Debe estar bien definido y no ser ambiguo.
- Debe ser finito.

##### Compuesto por:
- Datos de entrada.
- Proceso.
- Salida esperada.

##### Ejemplo:
```pseudocódigo
1. Inicio.
2. Leer un pedido.
3. Analizar estado del cliente.
4. Si el cliente no es deudor
	a. Escribir acepta el pedido.
5. Caso contrario
	b. Escribir rechaza el pedido.
6. Fin.
```


##### Diseño de un algoritmo
Problema ---> Diseño del algoritmo ---> Programa.

##### Diseño descendente
Descomposición de un problema en subproblemas más simples y estos a su vez en otros más simples aún.

##### Refinamiento
Dividir los problemas hasta alcanzar un grado de descomposición de las tareas que se asemeje a instrucciones que puedan ser volcadas a una computadora.
