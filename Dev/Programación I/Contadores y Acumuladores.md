##### Contador
Variable de tipo entero cuya función es contar cosas.
```pseudocódigo
cantidadDeNotas = cantidadDeNotas + 1;
```


##### Acumulador
Variable del tipo que se requiera que irá sumando valores a los que tenía guardados previamente.
```pseudocódigo
sumaParcial = sumaParcial + nota_1;
sumaParcial = sumaParcial + nota_2;
```

### UML (Unified Modeling Language)

Lenguaje estándar de modelado utilizado para representar sistemas de software mediante diagramas.

Incluye distintos tipos de diagramas como:

- Diagramas de clases
- Diagramas de casos de uso
- Diagramas de secuencia
- Diagramas de actividad
