Conjunto de instrucciones (acciones u operaciones) que pueden ser traducidas a lenguaje de máquina y nos permiten crear programas.

#### Tipos de instrucciones
- De [[Entrada - Salida]]
- Cálculo.
- Control.

#### Lenguajes de Abstracción
- Máquina (binario)
- Bajo nivel (Assembly)
- Alto nivel (C, C++, C#, Java)

#### Tipos de Programación
- Secuencial (go to)
- [[Programación Estructurada]] (modularidad)
- Lógica (hechos, relaciones, lógica formal)
- Orientada a objetos (POO)

#### Compilación (C, C++)
Se traduce todo el código fuente de una vez.
+Se ejecuta rápido ya que no necesita traducción adicional.
-Compilación lenta y requiere archivo ejecutable.

#### Interpretación (Python)
El código se traduce y ejecuta línea por línea en tiempo real.
+No requiere compilación previa.
-Programa más lento por interpretar mientras ejecuta.

**Fuertemente tipado**: tipos estrictos (C, C++, C#)
**Débilmente tipado**: permite conversiones entre tipos (Python)
