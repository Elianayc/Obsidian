El modelado de sistemas es el proceso de representar un sistema de software de manera abstracta, antes o durante su implementación, con el objetivo de comprender, diseñar y comunicar su estructura y comportamiento.

Permite visualizar cómo está compuesto un sistema, cómo interactúan sus partes y cómo fluye la información entre ellas.

Se utiliza para reducir la complejidad del sistema y facilitar su análisis, diseño e implementación.

#### Objetivos del modelado
- Comprender la estructura del sistema.
- Representar el comportamiento del sistema.
- Facilitar la comunicación entre desarrolladores.
- Reducir la complejidad del diseño.
- Servir como guía para la implementación.

- [[Diagrama de flujo]]

#### Relación con el desarrollo de software
El modelado de sistemas se utiliza como etapa previa o paralela a la implementación, ayudando a definir la estructura del sistema antes de codificarlo.
