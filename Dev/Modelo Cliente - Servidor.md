La **arquitectura cliente-servidor** es un modelo donde dos componentes de software cooperan para realizar una tarea:

- **Cliente:** realiza peticiones.
- **Servidor:** procesa las peticiones y envía respuestas.

La capacidad de procesamiento se distribuye entre ambos, permitiendo una mejor organización del sistema y una separación de responsabilidades.

---

## Ejemplos
Algunas aplicaciones que utilizan este modelo:

- Correo electrónico.
- Servidores de impresión.
- Servidores de archivos.
- World Wide Web.

---

## Configuraciones
Un servidor puede estar formado por diferentes programas y procesos:

- **1 programa - 1 proceso.**
- **1 programa - N procesos:** permite escalabilidad.
- **N programas - M procesos:** múltiples programas y procesos.

---

## Capas
El esquema más simple es la **arquitectura de 2 capas**.

A partir de este modelo pueden agregarse más capas, como:
- Capa de datos.
- Capa de negocio.
- Capa de seguridad.
