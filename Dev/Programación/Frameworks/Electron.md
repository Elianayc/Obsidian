**Electron** es un framework que permite crear **aplicaciones de escritorio multiplataforma utilizando tecnologías web**.

Permite utilizar HTML, CSS y JavaScript para desarrollar aplicaciones que pueden ejecutarse en sistemas operativos como Windows, macOS y Linux.

Electron combina tecnologías web con **Node.js** y el motor Chromium.

**Características principales**:

- Permite crear aplicaciones de escritorio con tecnologías web.
- Utiliza HTML, CSS y JavaScript.
- Integra **Node.js**.
- Permite desarrollar aplicaciones para Windows, macOS y Linux.
- Permite reutilizar conocimientos y tecnologías del desarrollo web.

**Ejemplo**:
Editores de código, clientes de escritorio y herramientas de productividad pueden desarrollarse utilizando Electron.
