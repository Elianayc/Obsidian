**.NET** es una **plataforma de desarrollo de software** creada por Microsoft que permite desarrollar diferentes tipos de aplicaciones.

Es un ecosistema que proporciona herramientas, bibliotecas y un entorno de ejecución para desarrollar aplicaciones utilizando distintos lenguajes, principalmente **C#**.

**Permite desarrollar**:
- Aplicaciones web.
- APIs y servicios Backend.
- Aplicaciones de escritorio.
- Aplicaciones móviles.
- Servicios y aplicaciones multiplataforma.

## Lenguajes
El lenguaje más utilizado dentro del ecosistema .NET es:

- [[C Sharp]] → lenguaje principal de desarrollo en .NET.

También pueden utilizarse otros lenguajes, como F# y Visual Basic.

## Desarrollo de aplicaciones de escritorio
.NET permite desarrollar aplicaciones de escritorio mediante diferentes tecnologías, entre ellas:

- **Windows Forms** → framework para crear aplicaciones de escritorio con interfaz gráfica, principalmente para Windows.
- **WPF (Windows Presentation Foundation)** → framework para crear aplicaciones de escritorio para Windows con interfaces más avanzadas y personalizables.
- **.NET MAUI** → permite desarrollar aplicaciones multiplataforma utilizando una misma base de código.

**Ejemplo**:
Una aplicación de gestión de stock con ventanas, formularios, botones y conexión a una base de datos puede desarrollarse utilizando **C# y .NET**.
