El **desarrollo de aplicaciones de escritorio** consiste en crear programas que se ejecutan directamente en computadoras.

Estas aplicaciones pueden desarrollarse específicamente para un sistema operativo o mediante tecnologías multiplataforma.

**Algunas tecnologías utilizadas son**:

- [[Electron]] → permite crear aplicaciones de escritorio utilizando tecnologías web como HTML, CSS y JavaScript.

- [[puntoNET]] → permite desarrollar aplicaciones de escritorio, entre otros tipos de aplicaciones.
