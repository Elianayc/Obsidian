Python es un lenguaje de programación de alto nivel, interpretado y de tipado dinámico.  

Está diseñado para ser simple, legible y productivo, por lo que es muy usado en educación, desarrollo web, automatización, ciencia de datos, inteligencia artificial y scripting.

Su filosofía prioriza que el código sea fácil de leer y escribir.

**Características principales**
- Sintaxis simple y clara.
- No requiere compilación (se interpreta).
- No necesita declarar tipos de variables.
- Gestión automática de memoria (garbage collector).
- Gran cantidad de librerías disponibles.

Es uno de los lenguajes más usados actualmente.

### **Sintaxis básica**

##### Programa mínimo:
```Python
print("Hola mundo")
```

En Python no existe la función `main()` obligatoria.

##### Variables
No se declara el tipo:
```Python
edad = 20
altura = 1.70
nombre = "Ana"
```
El tipo se determina automáticamente.

##### Condicional
```Python
if edad >= 18:    
	print("Mayor de edad")
else:    
	print("Menor de edad")
```
Python usa **indentación** (sangría) en lugar de llaves `{}`.

##### Bucle
```Python
for i in range(5):    
	print(i)
```

##### Función
```Python
def saludar(nombre):    
	print("Hola", nombre)
```
