#### Sin una clase: objeto literal

En JavaScript y TypeScript también se puede crear un objeto directamente utilizando `{ }`:

```
const persona = {
  nombre: 'Eliana',
  edad: 38,
};
```

Esto se llama **objeto literal**.

Su estructura básica es:

```
{
  propiedad: valor,
  propiedad: valor,
}
```

Por ejemplo:

```
const usuario = {
  username: 'Eliana',
  passwordLength: 8,
};
```
