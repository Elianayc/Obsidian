
## Etiquetas cerradas
Las etiquetas cerradas contienen un contenido dentro de ellas, generalmente texto.

**Ejemplo**:
```html
<p>Hola mundo!</p>
```

La etiqueta `<p>` se utiliza para representar un párrafo.

---

## Etiquetas abiertas
Las etiquetas abiertas no contienen contenido y se utilizan para insertar elementos específicos dentro del documento.

**Ejemplos**:
- Imágenes.
- Líneas horizontales.
- Otros elementos sin contenido interno.

**Ejemplo**:
```html
<hr>
```

La etiqueta `<hr>` permite insertar una línea horizontal.
