**Node.js** es un entorno de ejecución que permite ejecutar **JavaScript fuera del navegador**, principalmente en el lado del servidor.

Está construido sobre el motor **V8** de Google Chrome y permite utilizar JavaScript para desarrollar aplicaciones y servicios Backend.

**Se utiliza para**:
- Crear servidores web.
- Desarrollar APIs.
- Procesar solicitudes HTTP.
- Comunicarse con bases de datos.
- Crear aplicaciones y servicios Backend.
- Ejecutar código JavaScript del lado del servidor.

Una de sus características principales es su modelo de **procesamiento asincrónico y orientado a eventos**, que permite manejar múltiples operaciones de manera eficiente.

**Ejemplo**:
Un servidor desarrollado con Node.js puede recibir una solicitud de inicio de sesión, consultar una base de datos, validar las credenciales y devolver una respuesta al Frontend.
