Paradigma basado en la lógica formal y las matemáticas.  
Un programa se construye definiendo **hechos**, **relaciones** y **reglas**, y el sistema se encarga de deducir las respuestas.

En lugar de indicar _cómo_ resolver un problema paso a paso, se describe _qué se sabe_ y _qué se quiere averiguar_.

Ejemplo de idea:  
“Si X es padre de Y, y Y es padre de Z → entonces X es abuelo de Z”.
