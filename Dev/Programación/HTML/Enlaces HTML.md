Para crear enlaces dentro de un documento HTML se utiliza la etiqueta:

```HTML
<a>
```

La etiqueta `<a>` permite crear vínculos hacia otros documentos, recursos externos o partes específicas de la misma página.

Utiliza principalmente el atributo: `href`

El atributo `href` indica la dirección del recurso al que apunta el enlace.

**Ejemplo**:
```HTML
<a href="https://www.google.com">
    Ir a Google
</a>
```
