|                                                                                     **Compilación (C, C++)**                                                                                     |                                                             **Interpretación (Python)**                                                             |                                                                  **Transpilación (TypeScript, Babel)**                                                                   |
| :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: | :-------------------------------------------------------------------------------------------------------------------------------------------------: | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| Se traduce **todo** el código fuente de **una vez**.  <br>La **compilación** es **lenta** y genera un ejecutable.  <br>El programa final se **ejecuta rápido** porque ya está en código máquina. | El código se traduce y ejecuta **línea por línea**.  <br>**No requiere compilación previa.**  <br>Es más **lento** porque traduce mientras ejecuta. | Se traduce el código a **otro lenguaje de alto nivel**.  <br>No genera ejecutable, genera **otro código fuente**.  <br>Luego ese código debe ejecutarse o interpretarse. |
