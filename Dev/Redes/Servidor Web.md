Un **servidor web** es un software que almacena, procesa y entrega recursos web a los clientes, como navegadores, mediante solicitudes HTTP.

Funciona como intermediario entre el cliente y los recursos web (páginas, imágenes, archivos, etc.).

---

### Servidores web conocidos

Algunos ejemplos son:

- Apache HTTP Server.
- Nginx.
- Microsoft IIS.
- LiteSpeed Web Server.

---

### Contenido dinámico

Además de entregar páginas estáticas, algunos servidores web pueden ejecutar scripts para generar contenido dinámico utilizando lenguajes como:

- PHP.
- Python.
- Ruby.
- Node.js.
