**IPv4 (Internet Protocol version 4)** es la cuarta versión del Protocolo de Internet y el sistema de direccionamiento más utilizado.

## Características
- Utiliza direcciones de **32 bits**.
- Permite aproximadamente **4.300 millones** de direcciones únicas (2³²).
- Se representa mediante **cuatro números decimales** separados por puntos.

**Ejemplo:**
```
192.168.1.10
```

## Ventajas
- Amplia compatibilidad.
- Implementación sencilla.
- Es el protocolo más utilizado en la actualidad.

## Desventajas
- Cantidad limitada de direcciones IP.
- Requiere técnicas como **NAT (Network Address Translation)** para reutilizar direcciones.
- Menor soporte nativo para seguridad y autoconfiguración que IPv6.
