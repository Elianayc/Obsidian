HTTP es un protocolo **sin estado (*stateless*)**, es decir, cada petición es independiente de las anteriores.

Para mantener información entre solicitudes se utilizan mecanismos adicionales como:

- Cookies.
- Sesiones.
- Tokens de autenticación.

Estos permiten mantener información del usuario durante una interacción con una aplicación web.
