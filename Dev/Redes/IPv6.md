**IPv6 (Internet Protocol version 6)** es la versión más reciente del Protocolo de Internet, creada para reemplazar a IPv4 debido al agotamiento de direcciones.

## Características
- Utiliza direcciones de **128 bits**.
- Permite una cantidad prácticamente ilimitada de direcciones (**2¹²⁸**).
- Se representa mediante **ocho grupos hexadecimales** separados por dos puntos.

**Ejemplo:**
```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

## Ventajas
- Gran cantidad de direcciones disponibles.
- Mejor rendimiento del enrutamiento.
- Configuración automática de dispositivos.
- Soporte nativo para **IPsec**, mejorando la seguridad.
- Reduce la necesidad de NAT.

## Desventajas
- La migración desde IPv4 aún no está completamente finalizada.
- Algunos equipos o aplicaciones antiguas pueden no ser compatibles.
