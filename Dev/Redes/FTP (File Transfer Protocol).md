Protocolo utilizado para transferir archivos entre un cliente y un servidor.

Permite:
- Subir archivos.
- Descargar archivos.
- Renombrar, mover y eliminar archivos.

Funciona en la **capa de aplicación del modelo OSI**.

Puertos utilizados:
- **20:** transferencia de datos.
- **21:** comandos de control.
