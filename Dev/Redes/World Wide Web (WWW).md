Es una aplicación que funciona sobre Internet y permite acceder a información y servicios mediante un navegador web.

Se basa en:
- **[[HTTP]] (HyperText Transfer Protocol)** para la transferencia de páginas web.
- **[[HTML]] (HyperText Markup Language)** para estructurar y presentar la información.

> **Importante:** Internet y la Web **no son lo mismo**. La Web es una aplicación que utiliza Internet.
