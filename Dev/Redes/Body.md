El **body** contiene información enviada al servidor para ser procesada.

Generalmente se utiliza con:

- **POST:** creación de recursos.
- **PUT:** actualización completa.
- **PATCH:** actualización parcial.

> [!example]
> Enviar los datos de un usuario para registrarlo en una aplicación.
> 
> En una respuesta HTTP, el body puede contener el recurso solicitado, como HTML, imágenes o datos en formato JSON.
