Protocolo utilizado para el **envío de correos electrónicos**.

Se encarga de enviar mensajes:
- Desde un cliente al servidor de correo.
- Entre servidores de correo.

Puertos:
- **25:** comunicación estándar.
- **465 y 587:** versiones seguras.

No está diseñado para recuperar mensajes, sino para enviarlos.
