## SOAP (Simple Object Access Protocol)

Protocolo que permite la comunicación entre sistemas mediante el intercambio de mensajes en formato **XML**.

Características:
- Tiene una estructura definida con sobre (*Envelope*), encabezado y cuerpo.
- Puede utilizar HTTP como protocolo de transporte.
- Incluye características como seguridad y manejo de transacciones.

Es utilizado principalmente en sistemas empresariales y aplicaciones heredadas.
