Una **petición HTTP** ocurre cuando un cliente (por ejemplo, un navegador web) solicita un recurso a un servidor mediante una URL.

El proceso implica una comunicación entre el **cliente** y el **servidor**, donde el cliente envía una petición y el servidor devuelve una respuesta.
