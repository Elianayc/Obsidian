Una petición **HTTP (*request*)** es un conjunto de datos que sigue las reglas definidas por el protocolo HTTP para permitir la comunicación entre cliente y servidor.

Tanto las peticiones como las respuestas utilizan una estructura similar basada en headers y body. La diferencia está en la información que contienen y en el momento de la comunicación en que aparecen.

**Una petición puede contener**:

- **[[URL]]:** indica el recurso solicitado.
- **[[Header]] (encabezado):** contiene información adicional sobre el cliente, el recurso y la comunicación.
- **[[Method]] (método o verbo):** indica la acción que se desea realizar.
- **[[Body]] (cuerpo):** contiene datos enviados al servidor.
- **[[Parameters]] (parámetros):** información adicional enviada generalmente mediante la URL.
- **[[State]] (estado):** información relacionada con el estado de la comunicación.
