**[[TCP]]/[[IP]] (Transmission Control Protocol / Internet Protocol)** es el conjunto de protocolos de comunicación que define cómo deben viajar los datos a través de Internet, haciendo posible su funcionamiento.

Se utiliza para la comunicación en redes y proporciona conectividad de extremo a extremo, especificando cómo los datos deben ser:

- Formateados.
- Direccionados.
- Transmitidos.
- Enrutados.
- Recibidos.
