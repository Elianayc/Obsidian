El **desarrollo de aplicaciones móviles** es la disciplina dedicada a crear aplicaciones destinadas a dispositivos móviles como smartphones y tablets.

Las aplicaciones pueden desarrollarse específicamente para un sistema operativo o mediante tecnologías que permiten compartir código entre diferentes plataformas.

**Ejemplo de tecnología**:

- [[React Native]] → permite desarrollar aplicaciones móviles para Android e iOS utilizando React y JavaScript/TypeScript.
