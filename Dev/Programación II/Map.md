Un Map es una estructura de datos que almacena pares **clave–valor**.
Cada elemento está compuesto por una clave única (**key**) y un valor asociado (**value**).

**No permite claves duplicadas**, pero sí **valores repetidos**.
Se utiliza cuando queremos acceder rápidamente a un dato a través de una clave en lugar de un índice.


#### Tipos
- [[HashMap]] --> Rápido, sin orden.
- [[LinkedHashMap]] --> respeta orden de inserción.
- [[TreeMap]] --> Ordena por clave.
