Es una relación **débil** entre objetos.

Representa una relación de tipo **“puede tener”** (compuesto + componente).  
El objeto principal **no depende del componente para existir**.  
El componente puede existir de forma independiente.

Se da cuando una clase tiene atributos cuyo tipo es otra clase, pero no es necesario para su existencia.

**Ejemplo:**  
Auto + Aire Acondicionado  
El auto puede existir sin aire acondicionado.
