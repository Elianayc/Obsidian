Los controles de formulario permiten que el usuario ingrese datos o seleccione opciones.

---

# Ingreso de texto
Existen diferentes controles para ingresar texto.

---

## Caja de texto de una línea

Permite ingresar texto en una sola línea.
No permite utilizar la tecla Enter para crear saltos de línea.

**Ejemplo**:
```html
<input type="text">
```

---

## Campo de contraseña

Permite ingresar información cuyo contenido no será visible.

**Ejemplo**:
```html
<input type="password">
```

El navegador reemplaza los caracteres ingresados por símbolos ocultos.

---

## Área de texto multilínea

Permite ingresar una o varias líneas de texto.

Se utiliza la etiqueta:
```html
<textarea>
```

**Ejemplo**:
```html
<textarea>
Comentarios
</textarea>
```
