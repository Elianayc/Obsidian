Para insertar imágenes se utiliza la etiqueta:
```html
<img>
```

Es una etiqueta que no necesita cierre porque no contiene contenido interno.

**Ejemplo**:
```html
<img src="imagen.jpg">
```

---

## Atributo `src`

Indica la ubicación del archivo que se desea mostrar.

Puede ser:
- Una URL externa.
- Una ruta dentro del proyecto.

**Ejemplo**:
```html
<img src="imagenes/foto.jpg">
```

---

## Atributo `alt`

El atributo `alt` contiene un texto alternativo que describe la imagen.

Debe ser:
- Breve.
- Claro.
- Representativo del contenido visual.

**Ejemplo**:
```html
<img src="perro.jpg" alt="Perro jugando en el parque">
```

Este texto es importante para accesibilidad y para casos donde la imagen no pueda cargarse.
