
El signo **/** se utiliza para indicar el cierre de una etiqueta.

**Ejemplo**:
```html
<p>Texto</p>
```

El signo aparece únicamente en la etiqueta de cierre:
```html
</p>
```

A partir de **HTML5**, el uso del signo `/` en etiquetas sin contenido es opcional.


Por lo tanto:

```html
<hr>
```

y

```html
<hr/>
```

son equivalentes.
