HTML permite crear diferentes tipos de listas:

---

## Lista ordenada

Se crea utilizando la etiqueta:
```html
<ol>
```

Los elementos de la lista se agregan mediante:
```html
<li>
```

**Ejemplo**:
```html
<ol>
    <li>Primer elemento</li>
    <li>Segundo elemento</li>
</ol>
```

Los elementos aparecen utilizando una numeración.

---

## Lista no ordenada

Se crea utilizando la etiqueta:
```html
<ul>
```

También utiliza la etiqueta:
```html
<li>
```

para cada elemento.

**Ejemplo**:
```html
<ul>
    <li>Elemento uno</li>
    <li>Elemento dos</li>
</ul>
```

Los elementos aparecen mediante viñetas.

---

## Lista de definición

Se utiliza para representar términos y sus descripciones.

Está formada por:

|Etiqueta|Función|
|---|---|
|`<dl>`|Define la lista de definición|
|`<dt>`|Define el término|
|`<dd>`|Define la descripción del término|

**Ejemplo**:
```html
<dl>
    <dt>HTML</dt>
    <dd>Lenguaje de marcado utilizado para crear páginas web.</dd>
</dl>
```
