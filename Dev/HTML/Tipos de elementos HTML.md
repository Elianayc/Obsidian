Los elementos HTML que se encuentran dentro del documento se pueden dividir en dos grupos principales:

## Elementos de bloque

Los elementos de bloque:
- Ocupan, por defecto, el **100% del ancho disponible** de su contenedor.
- Se muestran uno debajo de otro.
- Generan un salto de línea antes y después del elemento.

Ejemplos:
- Párrafos.
- Encabezados.
- Divisiones.

---

## Elementos de línea (inline)

Los elementos de línea:
- Ocupan solamente el espacio necesario según su contenido.
- Se muestran uno al lado del otro.
- No generan un salto de línea automático.

Ejemplos:
- Enlaces.
- Elementos para modificar partes de un texto.
