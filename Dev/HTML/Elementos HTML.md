Cada par de etiquetas HTML forma un **elemento HTML**.

Un elemento está compuesto por:
- Etiqueta de apertura.
- Contenido.
- Etiqueta de cierre.
  
![[Pasted image 20260807152803.png]]

**Ejemplo**:
```html
<h1>Título principal</h1>
```

En este caso:
- `<h1>` indica el inicio del elemento y define un encabezado.
- `Título principal` es el contenido del elemento.
- `</h1>` indica el cierre del elemento.

Los elementos pueden contener:
- Texto.
- Otros elementos HTML.
- Atributos.

# Elementos HTML principales

|Elemento|Tipo|Descripción|
|---|---|---|
|`<p>`|Bloque|Representa un párrafo formado principalmente por texto|
|`<br>`|Línea|Inserta un salto de línea simple|
|`<strong>`|Línea|Marca un texto con especial importancia o énfasis fuerte|
|`<em>`|Línea|Indica énfasis en un texto, generalmente representado en cursiva|
