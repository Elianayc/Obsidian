Los formularios permiten que el usuario ingrese o seleccione información que luego será enviada y procesada por el sistema.

Para crear un formulario se utiliza la etiqueta:
```html
<form>
```

Un formulario funciona como un contenedor de diferentes controles de entrada, como:

- Campos de texto.
- Contraseñas.
- Botones.
- Opciones de selección.

# Resumen

|Elemento|Función|
|---|---|
|`<table>`|Crea una tabla|
|`<tr>`|Define una fila|
|`<th>`|Define una celda de encabezado|
|`<td>`|Define una celda de datos|
|`<form>`|Crea un formulario|
|`<input>`|Permite ingresar datos|
|`<textarea>`|Permite ingresar texto multilínea|
|`<button>`|Ejecuta acciones|
|`<select>`|Crea un menú desplegable|
|`<option>`|Define opciones de selección|
