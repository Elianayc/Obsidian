Todas las etiquetas HTML pueden aceptar **atributos**.

Un atributo es una característica adicional que permite modificar o agregar información a un elemento.

**Ejemplos**:
- En una imagen:
    - Ancho.
    - Alto.
- En un texto:
    - Color.
    - Tipo de fuente.

**Ejemplo**:
```html
<img src="imagen.jpg" width="200" height="100">
```

En este caso:
- `src` indica la ubicación de la imagen.
- `width` define el ancho.
- `height` define el alto.

---

## Características de los atributos
Una etiqueta puede tener más de un atributo.

Cuando existen varios atributos:
- Deben separarse mediante espacios.
- Se colocan únicamente en la **etiqueta de apertura**.

**Ejemplo**:
```html
<img src="foto.jpg" width="300" height="200">
```

Los atributos `src`, `width` y `height` pertenecen a la etiqueta de apertura `<img>`.
