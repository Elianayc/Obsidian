En HTML, los elementos se definen mediante **etiquetas**.

Las etiquetas HTML indican el **inicio y el final** de cada elemento. El contenido que se encuentra dentro de ellas es el que será interpretado y formateado por el navegador.

La mayoría de las etiquetas HTML funcionan mediante un par:

- **Etiqueta de apertura** → indica dónde comienza el elemento.
- **Etiqueta de cierre** → indica dónde finaliza el elemento.

**Ejemplo**:
```html
<p>Hola mundo!</p>
```

En este caso:
- `<p>` es la etiqueta de apertura.
- `Hola mundo!` es el contenido.
- `</p>` es la etiqueta de cierre.
