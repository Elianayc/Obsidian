Las **unidades absolutas** establecen completamente el valor de una medida, ya que este no depende de otro valor de referencia.

Las unidades absolutas definidas por CSS son:

|Unidad|Significado|
|---|---|
|`in`|Pulgadas (_inches_). Una pulgada equivale a 2,54 centímetros.|
|`cm`|Centímetros.|
|`mm`|Milímetros.|
|`pt`|Puntos. Un punto equivale a 1/72 de pulgada, aproximadamente 0,35 mm.|
|`pc`|Picas. Una pica equivale a 12 puntos, aproximadamente 4,23 mm.|

### Ventajas y desventajas

La principal ventaja de las unidades absolutas es que su valor es directamente el valor que se debe utilizar, sin necesidad de realizar cálculos intermedios.

Su principal desventaja es que son **poco flexibles** y no se adaptan fácilmente a diferentes medios.

De todas las unidades absolutas, la que suele utilizarse es el **punto (`pt`)**, especialmente para establecer el tamaño del texto en documentos que se van a imprimir.
