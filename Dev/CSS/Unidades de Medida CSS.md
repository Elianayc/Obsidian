Las **unidades de medida en CSS** se utilizan, entre otras cosas, para definir:

- Alto de los elementos.
- Ancho de los elementos.
- Márgenes.
- Tamaño de letra.

Todas las medidas se indican mediante un **valor numérico** seguido de una **unidad de medida**, sin ningún espacio entre ambos.

**Ejemplo**:
```
p {
    font-size: 10px;
}
```

CSS divide las unidades de medida en dos grupos:

- **[[Unidades absolutas]]**
- **[[Unidades relativas]]**
