## Reglas de Codd

Las **12 reglas de Codd** definen cuándo un sistema puede considerarse verdaderamente relacional.

### Reglas más importantes

**Regla 0 — Regla Fundamental**
- El sistema debe gestionar la base de datos únicamente mediante capacidades relacionales.

**Regla 1 — Regla de la Información**
- Toda la información debe almacenarse como valores dentro de tablas.

**Regla 2 — Acceso Garantizado**
- Cada dato debe poder accederse mediante:
  - Nombre de la tabla
  - Clave primaria
  - Nombre de la columna

**Regla 8 — Independencia Física**
- Los cambios en el almacenamiento físico no deben afectar a las aplicaciones.

**Regla 12 — No Subversión**
- Ningún lenguaje de bajo nivel puede evitar las restricciones de integridad del modelo relacional.
