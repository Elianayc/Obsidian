Un Array es una colección ordenada de elementos que **permite duplicados**.

**Mantiene el orden de inserción** y permite acceder a los elementos por **índice**.

Es la estructura más utilizada en [[TypeScript]].

> [!example]
> 
> ```ts
> const list: number[] = [];
> 
> list.push(10);
> list.push(20);
> list.push(20);
> 
> console.log(list);
> ```
> 
> `.pop()` Borra el último elemento.
> 
> `for(const numero of numeros){console.log(numero);}` Recorrido.
