**Angular** es un **framework de desarrollo web** basado en TypeScript, desarrollado por Google.

Se utiliza principalmente para crear aplicaciones Frontend completas y estructuradas.

**Características principales**:

- Arquitectura basada en **componentes**.
- Utiliza TypeScript.
- Incluye herramientas para manejar formularios y rutas.
- Permite realizar solicitudes HTTP para comunicarse con APIs.
- Facilita el desarrollo de aplicaciones de una sola página (**SPA**).
- Proporciona una estructura definida para organizar aplicaciones grandes.

**Ejemplo**:
Una aplicación empresarial puede utilizar Angular para crear las distintas pantallas, formularios, navegación y comunicación con las APIs del Backend.
