
### Función principal
**TypeScript** es un lenguaje de [[programación]] basado en **[[JavaScript]]** que agrega características adicionales para facilitar el desarrollo de aplicaciones grandes y complejas.

Su principal aporte es incorporar **tipado estático**, permitiendo detectar errores antes de ejecutar el programa y mejorar la organización del código.

TypeScript se compila a JavaScript para poder ejecutarse en navegadores y entornos compatibles.

---

### Características principales
TypeScript agrega:

- **Tipado estático:** permite definir qué tipo de dato puede contener una variable, parámetro o retorno de una función.
- **Detección temprana de errores:** encuentra problemas durante la etapa de compilación.
- **Mejor autocompletado y herramientas de desarrollo:** facilita la escritura y mantenimiento del código.
- **Programación orientada a objetos:** incorpora clases, interfaces, [[herencia]] y modificadores de acceso.

---

### Ejemplo

```javascript
function sumar(a, b) {
    return a + b;
}
```

```typescript
function sumar(a: number, b: number): number {
    return a + b;
}
```
