El DQL (Data Query Language) es la parte de SQL encargada de la **consulta y recuperación de datos** dentro de una base de datos relacional.

Su comando principal es:
[[SELECT]]

## Características
- Consulta datos sin modificarlos
- Permite trabajar con una o varias tablas
- Se apoya principalmente en SELECT
- Permite filtros, agrupaciones y ordenamientos
- Devuelve siempre un conjunto de resultados (tabla virtual)
