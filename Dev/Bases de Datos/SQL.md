SQL (Structured Query Language) es un lenguaje de consulta estructurado utilizado para comunicarse con bases de datos.
Se utiliza principalmente en el modelo relacional.

#### Tipos de comandos SQL
- [[DDL]] → definición de la estructura (tablas, campos, etc.)
- [[DML]] → manipulación de datos (insertar, modificar, eliminar)
- [[DQL]] → consultas de datos (SELECT)
- [[DCL]] → control de permisos y seguridad
- [[TCL]] → control de transacciones
