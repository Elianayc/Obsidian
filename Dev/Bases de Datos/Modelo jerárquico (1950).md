Presenta una estructura en forma de árbol invertido.

Las tablas establecen relaciones **padre-hijo**:
- Un padre puede tener múltiples hijos
- Cada hijo tiene un único padre

### Mejora respecto a File Systems
- Permite relaciones 1 a N

### Desventajas
- Es necesario conocer toda la estructura para acceder a los datos
- Modelo rígido
- Modificaciones estructurales complejas
