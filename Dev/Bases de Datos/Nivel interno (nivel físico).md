Es “cómo se guardan realmente los datos”

Es el nivel más bajo.
- También llamado nivel físico
- Se encarga del almacenamiento real

### Características:
- Define cómo se guardan los datos en disco
- Maneja estructuras internas como:
    - registros
    - índices
    - organización física


### Ejemplo:
- Un empleado puede ocupar 20 bytes:
    - 6 bytes código
    - 4 bytes departamento
    - 10 bytes salario


### No incluye:
- consultas
- vistas de usuario
- lógica de aplicación
