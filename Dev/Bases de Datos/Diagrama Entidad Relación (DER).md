Un ERD es un diagrama que representa:
- **Entidad (tablas)**
- **Relación entre entidades**
- [[Cardinalidad]] → cantidad de asociaciones posibles entre entidades
- [[Claves]] → identificadores que permiten relacionar y distinguir entidades**

Se utiliza para **diseñar la estructura de una base de datos antes de implementarla en SQL**, funcionando como un modelo previo al modelo relacional físico.
