SQL (Structured Query Language) es un lenguaje de consulta estructurado utilizado para comunicarse con bases de datos.

Se utiliza principalmente en el modelo relacional.

#### Tipos de comandos SQL

- [[DDL (Data Definition Language)]] → definición de la estructura (tablas, campos, etc.)
- [[DML (Data Manipulation Language)]] → manipulación de datos (insertar, modificar, eliminar)
- [[DQL (Data Query Language)]] → consultas de datos (SELECT)
- [[DCL (Data Control Language)]] → control de permisos y seguridad
- [[TCL (Transaction Control Language)]] → control de transacciones
