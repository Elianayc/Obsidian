## Entity Relationship Diagram
Un ERD es un diagrama que representa entidades (tablas) y las relaciones entre ellas.
Se utiliza para diseñar la estructura de una base de datos antes de implementarla en SQL.
![[Diagrama ERD.png|927]]

### Cardinalidad (cero, uno o muchos)
Define la obligatoriedad de una relación.
Cero indica que la relación puede no existir.
Uno indica que la relación es opcional o única según el caso.
Muchos indica que puede haber múltiples registros relacionados.
