Es “la base de datos como la ve el usuario”.

- También se llama **nivel lógico de usuario**.
- Es el nivel más cercano a las personas.

###  Características:
- Cada usuario puede ver los datos de forma distinta (vistas).
- Puede haber muchas vistas externas para la misma base de datos.

###  Ejemplo:
- Tesorería ve todos los datos del empleado.
- RRHH ve solo código y departamento.


###  Quién lo usa:
- Usuarios finales.
- Desarrolladores.
- DBA.


###  Tecnologías/lenguajes:
- Interfaces gráficas o consultas SQL.
- Lenguajes de programación (Java, C++, PHP, etc.)
- Uso de DDL y DML.
