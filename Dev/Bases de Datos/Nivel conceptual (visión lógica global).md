Es “el diseño lógico de la base de datos”.

- También llamado nivel lógico (sin calificar).
- Es **único en toda la base de datos**.

###  Características:
- Define qué datos existen y cómo se relacionan.
- No depende de cómo se guardan físicamente.
- No muestra detalles de almacenamiento.

### Ejemplo:
Entidad **Empleado**:
- código
- departamento
- salario

Se define con DDL.
