Para agregar y utilizar **iconos** dentro de una página web, podemos incluir una **hoja de estilos** y luego referenciar las clases proporcionadas por dicha hoja en los elementos HTML donde necesitemos utilizar los iconos.

Por ejemplo, podemos utilizar los iconos proporcionados por **Font Awesome**.

También podemos utilizar los iconos de **Google**.

Los iconos pueden incorporarse, por ejemplo, a los elementos de un menú de navegación:

```css
<ul>
    <li><a href="#">⌂ Home</a></li>
    <li><a href="#proyectos">Proyectos</a></li>
    <li><a href="#">Applications</a></li>
    <li><a href="#">Settings</a></li>
</ul>
```
